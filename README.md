# Question Paper Intelligence

This repository contains the project structure for the Question Paper Intelligence platform.

## Structure

- `docs/` — product requirements and documentation
- `design/stitch/` — design and wireframe assets
- `frontend/` — user-facing application
- `backend/` — APIs and core services
- `agents/` — AI/automation agents and orchestration logic

## Getting Started

1. Review the product requirements in `docs/PRD.md`.
2. Inspect the design assets in `design/stitch/`.
3. Start building the frontend and backend modules.
4. Add AI agents under `agents/` as features are introduced.
